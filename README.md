## 🧪 How I Work

A lot of my development philosophy comes from building systems that I personally have to operate.

**Build → Test → Break → Fix → Improve → Deploy**

I use AI extensively throughout that process, but as a development tool rather than a replacement for understanding the system.

AI helps me research, debug, explore architectures, analyze problems, generate alternatives, and move faster. The responsibility for understanding what gets deployed still belongs to the developer.
